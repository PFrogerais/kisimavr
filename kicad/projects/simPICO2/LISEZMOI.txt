simPICO2 - Raspberry Pi Pico 2 (RP2350) : LED, bouton, ADC, UART
================================================================

Meme montage que simPICO, avec une Pico 2 a la place de la Pico.

Modeles : generes par "cmake --build build --target demos" (tools/setup_demos.py) :
  - pico2.lib    : A1 = Raspberry Pi Pico 2 (symbole officiel MCU_Module:RaspberryPi_Pico :
                   la Pico 2 a le meme brochage, empreinte Module:RaspberryPi_Pico_Common_Unspecified),
                   firmware firmware/pico2/pico2_demo_riscv.bin (make -C firmware/pico2)
  - terminal.lib : U2 = adaptateur USB-serie 3,3 V + terminal du PC
  - led_models.lib : LED D1, diode D2

Le RP2350 est emule par rp2350js (fork de rp2040js) execute par QuickJS dans
le plug-in mcu_cosim.so : rien a installer en plus. La bootrom A2 du RP2350
demarre le firmware comme sur la puce (bloc IMAGE_DEF) ; les coeurs sont
RISC-V (Hazard3) ou Arm (Cortex-M33) selon le firmware.

Cablage : identique a simPICO
  GP0 (TX) -> RXD de U2, GP1 (RX) <- TXD de U2 (115200 bauds)
  GP14 : bouton (D2 + V1 : appuye de 3 a 6 ms), pull-up interne
  GP15 : signal carre 1 kHz (label SQ)
  GP16 : LED D1 via R1 330 Ohm, allumee pendant l'appui
  GP26 (ADC0) : pont R2 10k / R3 4,7k sur 3V3 -> 1,06 V
  GP25 : LED de la carte, dans le modele

Firmware : firmware/pico2/pico2_demo.c (bare-metal, sans SDK, clang + lld),
compile pour les deux architectures :
  pico2_demo_riscv.bin (utilise ici) et pico2_demo_arm.bin
  "Pico 2 pret (RISC-V)", puis "ADC0 = 1314 (1.06 V)" toutes les 4 ms,
  et "Recu : <ligne>" pour chaque ligne recue.
Avec le Pico SDK (PICO_BOARD=pico2, PICO_PLATFORM=rp2350-riscv ou rp2350) ou
Arduino-pico (carte "Raspberry Pi Pico 2") : regenerer le modele avec le .uf2 :
  python3 tools/make_pico_lib.py --mcu rp2350 --fw mon_prog.uf2 -o pico2.lib
L'emulation Arm (Cortex-M33) de rp2350js est plus jeune que l'emulation
RISC-V : un firmware Arm peut rencontrer une instruction ou un peripherique
non emule (message "RP2350 ..." dans le terminal).

Ou voir quoi ?
  - Terminal (KiCad lance depuis un terminal) : UART0> ... ; uart_log.txt
  - Simulateur : sonder SQ, LED, BTN, TX, RX, POT

Simulation : transitoire, pas 0.5u, duree 12m (environ 10 s de calcul : le
RP2350 a 150 MHz est plus long a emuler que le RP2040).
Guide detaille : README.md du dossier parent.

Terminal externe : l'UART0 est aussi sur un port serie virtuel, ~/kisimavr_uart0 :
  picocom -b 115200 ~/kisimavr_uart0      (ou CuteCom, GTKTerm, screen)
KiCad en Flatpak : serveur TCP local a la place, nc localhost 5555 ou
  socat pty,link=$HOME/kisimavr_uart0,raw,echo=0 tcp:localhost:5555 puis CuteCom.
Ce qu'on tape arrive sur RX du microcontroleur (README.md, section 6.7).
